# Texas Hold'em Poker Game

Текстова гра техаський покер з ботом для тренування. Три рівні складності.

## Інсталяція

```bash
git clone https://github.com/stadnika/texas-holdem-poker.git
cd texas-holdem-poker
python poker_game.py
```

## Правила

- Кожному гравцю видається по 2 приватні карти
- Раунди ставок: Pre-Flop, Flop, Turn, River
- Можливі дії: Fold (скинути), Check (пропустити), Call (коллувати), Raise (підвищити)
- Переможець визначається найсильнішою комбінацією з 5 карт (2 приватні + 5 спільних)

## Складність

- **Easy (Легка)**: Бот часто фолдить, грає консервативно
- **Medium (Середня)**: Бот грає розумно, аналізує сильність рук
- **Hard (Складна)**: Бот грає агресивно, добре читає опонента

## Гра

1. Запустіть гру: `python poker_game.py`
2. Виберіть рівень складності (1-3)
3. Грайте проти бота
4. Вводьте команди: `fold`, `check`, `call`, `raise`
