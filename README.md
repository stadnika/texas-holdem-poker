# Texas Hold'em Poker

Простий покер в графічному вікні з ботом і трьома рівнями складності.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # або .venv\Scripts\activate на Windows
pip install -r requirements.txt
python main.py
```

## Особливості

- 3 складності: easy, medium, hard
- Графічне вікно на Pygame
- Картки в стилі карткової гри
- Проста логіка бота і раундів
- Кнопки дій: Fold, Check, Call, Raise

## Примітка

Це базова ігрова версія з простим інтерфейсом, призначена для навчання і тренування логіки покеру.
